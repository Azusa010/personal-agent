## 1. 任务背景与核心业务目标

本项目正由单一的一次性 Coding Session 辅助工具演进为具备伴随感、长期记忆与角色化人格的 **个人全能智能体（Personal Agent）**，深度融合 OpenAI Dots、xAI Grok Bot、Meta Muse 及 Pi Agent 的交互范式。

本次交接的核心目标是：
1. **废弃无状态的临时会话中心**：将会话升级为由持久化 Bot 主导的伴侣会话体系；
2. **多角色与人设注入**：支持默认智能体及特定专业角色（如「代码极客 💻」、「深度分析师 🔍」及用户自定义智能体），每个角色拥有独立的 System Persona Prompt、形象及专属常驻会话；
3. **前端 UI/UX 极致降噪**：重塑侧栏、欢迎页、输入框与思考链轨迹，移除繁杂冗余的操作标签与内部审查通知，提供沉浸干净的对话体验。

## 3. 核心设计决策与避坑记录

1. **会话去重与生命周期隔离**：
   - 每个 Bot 绑定一个固定的 `conversationId`（如 `c-bot-coder`）；
   - 侧边栏分组必须使用 `botConvIds` 集合过滤常规历史会话，否则历史列表中会出现大量重复的「与 代码极客 的对话」。
2. **React 19 / ESLint 规范**：
   - 弹窗（Dialog）内的重置逻辑禁止在父级使用 `useEffect(() => { setState(...) }, [open])`，这会导致 `Calling setState synchronously within an effect` 门禁报错；
   - 采用 `<BotForm key={bot?.id ?? 'new'} />` 模式，由挂载生命周期自然初始化状态。
3. **安全审查卡片展现策略**：
   - Sidecar 独立安全审查是系统的核心防护网，审计事件 `sidecar_inspected` 在数据流中依然完整记录；
   - 仅在展示层（`ThoughtChainViewer`）将 `noticeKind === 'sidecar'` 做静默放行不渲染，避免每次调用工具时打断阅读心智。
