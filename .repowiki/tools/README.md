# 维护工具

`.repowiki` 是代码库 wiki 的生成快照，本目录放维护它的脚本（不属于 wiki 内容本身）。

## check-anchors.mjs

全 wiki 锚点校验，**每次增量更新后必跑**：

```bash
node .repowiki/tools/check-anchors.mjs
```

查四类问题：

1. **越界**——`end` 超过目标文件真实行数 + 1（+1 是生成器对「整文件引用」的惯例）；
2. **缺失**——锚点指向的源文件在仓库里不存在；
3. **畸形**——片段不是 `L起-L止`（历史上出现过漏写第二个 L 的 `#L1-245`、`#LL`、中文数字锚）；
4. **显示文本与目标行号不一致**——`[path:起-止](file://path#L起-L止)` 两处要同时改，只改一边读者看到的行号与跳转结果就对不上（批量替换时最容易只改「file://」那一半）。

行号必须对**当前工作区**文件成立：并行会话的未提交改动会让行数变动，所以先落代码、再改 wiki，跑校验才准。

替换锚点时别用 `sed`/`perl` 直接改半边（中文路径在 Git Bash 下还会打不开）：用 Node 脚本按「整条链接」一起替换，改完立刻跑一遍本脚本。
